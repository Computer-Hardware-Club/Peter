# Publishing changes

For every requested change to this project, push the tested changes to
`main` at `git@github.com:Computer-Hardware-Club/Peter.git`, deploy the
applicable changes to Peter, and verify the deployment before reporting
completion.

From the workstation, Peter is reachable over SSH at `192.168.1.12`.
The installed application lives at `/opt/workshop`. Check the installed
files before updating them. Peter has deployment-specific VPN and terminal
integration, so apply the relevant changes to the installed version when
it differs from GitHub. Preserve active workshop sessions during updates.
